CalendarApp Kotlin ? Quick reference

Appointment input pipeline

Turn a selected date and two text fields into one in-memory appointment, then refresh the daily presentation.

select date ? read inputs ? validate ? construct ? add ? refresh

Shared callback state

private var selectedDateKey: String? = null

// Inside CalendarView listener:
selectedDateKey = dateKey

An activity property is visible to both callbacks. null means no date has been selected yet.

Mutable storage

private val appointments = mutableListOf(
    Appointment("2026-10-11", "Doctor", "11:30")
)

val fixes the list reference. MutableList permits changing its contents. This storage disappears when the process restarts.

Click-listener skeleton

button.setOnClickListener {
    val dateKey = selectedDateKey
    val title = titleInput.text.toString().trim()
    val time = timeInput.text.toString().trim()

    if (dateKey == null) return@setOnClickListener
    if (title.isBlank() || time.isBlank()) return@setOnClickListener

    appointments.add(Appointment(dateKey, title, time))
    dailySummaryText.text = buildDailySummary(dateKey)
}

Ownership check

  • EditText owns the typed characters.
  • selectedDateKey remembers the selection between callbacks.
  • appointments owns appointment records in memory.
  • buildDailySummary queries records and creates display text.
  • dailySummaryText presents the result; it is not storage.
