CalendarApp Kotlin · Quick reference

Hybrid calendar data model

Store records by feature; combine matching records when a date is selected.

AppointmentsHabit checksPeriod logs → filter by date → daily view

Record types

data class Appointment(
    val dateKey: String,
    val title: String,
    val time: String
)

data class HabitCheck(
    val dateKey: String,
    val habitName: String,
    val complete: Boolean
)

data class PeriodLog(
    val dateKey: String,
    val flow: String,
    val notes: String
)

Daily query pattern

val matchingRecords = records.filter { record ->
    record.dateKey == selectedDateKey
}

filter returns matching records without changing the original collection. The daily view owns presentation; feature collections own the data.

Habit display

val mark = if (habit.complete) "☑" else "☐"
val row = "$mark ${habit.habitName}"

Incomplete and unrecorded intentionally share the unchecked state.
